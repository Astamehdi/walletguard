What this is

WalletGuard is a small Solana dApp that gives everyday users one place to ask a simple question: is this thing safe? — a wallet address, a link someone sent them, or a program they are about to interact with. Connect your Phantom wallet, paste anything, get a plain-language answer.

Address checks — DD.xyz Threat Risks API URL checks — DD.xyz URL Risk API Contract checks — DD.xyz Contract Risk API

Risk scoring is provided by the DD.xyz (Webacy) Risk Engine and plugs into the three marked slots. This build ships the finished interface and integration contract; live scoring connects as soon as API credentials are issued. Everything runs client-side — no accounts, no tracking.
